## Changes

pickaxe.py v0.3.4 -> v0.3.6:

v0.3.5 — backup/restore (PX-B4):
  backup_workspace(root, dest, skip_working_tree, force):
    discovers all repos; creates bundles/ via git bundle create --all;
    optionally copies working tree; writes manifest.json. Guard: raises
    FileExistsError if dest non-empty without --force.
  restore_workspace(backup, dest):
    reads manifest.json; git clones each bundle to target path; re-adds
    origin remote. Returns [{rel, status}] (ok/already_exists/missing_bundle/
    clone_failed).
  _render_backup_table, _render_restore_table, _cmd_backup, _cmd_restore
  CLI: backup [root] --to DEST [--skip-working-tree] [--force] [-f table|json]
  CLI: restore [backup] --to DEST [-f table|json]
  Fixes: datetime.utcnow() -> datetime.now(tz) (Python 3.14 deprecation);
    unicode arrow -> ASCII (Windows cp1252); --force flag for partial dest.

v0.3.6 — discover drift (PX-D1):
  discover_remote_drift(root):
    walks root via discover(); fetches each origin; measures ahead/behind/dirty
    per repo. flags: push-needed | behind | uncommitted | no-remote | fetch-failed.
  _render_drift_table(results): flags + remote columns, summary count.
  _cmd_discover: replaces "not yet implemented" stub for noun=='drift'.
  Replaces standalone drift_check.py prototype (deleted).
